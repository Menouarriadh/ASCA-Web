# 🧠 ASCA – Association pour la Santé de Cerveau Annaba

Official website for **ASCA** — a scientific association dedicated to **Cerebral Health**, Neuroscience, and Neuropharmacology, based in **Annaba, Algeria**.

> Open to **everyone** — students, healthcare professionals, researchers, and any citizen who wants to contribute to improving cerebral health.

## 🚀 Deploy to GitHub Pages (Step-by-Step)

1. **Create a new GitHub repository** named `asca-website` (or any name).
2. **Upload** `index.html`, `logo.jpg`, and `README.md` to the repository root.
3. Go to your repo → **Settings** → **Pages**.
4. Under **Source**, select `main` branch and `/ (root)` folder.
5. Click **Save** — your site goes live at:
   ```
   https://YOUR-USERNAME.github.io/asca-website/
   ```

## 🖼️ Logo Setup

Place your ASCA logo in the same folder as `index.html` and name it **`logo.jpg`**.

## ✨ Features

- Animated **neural network** particle background (Canvas API)
- **Floating ASCA logo** with glowing orbital ring animation
- **About section** with 4 frosted-glass mission cards
- **Audience banner** — clearly states ASCA is open to all, not just students/professionals
- **5 social media cards** (TikTok, Instagram, Facebook, LinkedIn, YouTube) with platform-specific hover glows
- **Contact section** with clickable email link
- **Scroll reveal** animations via Intersection Observer
- Fully **responsive** — mobile-first design
- **Zero dependencies** — pure HTML/CSS/JS, no npm or build step needed
